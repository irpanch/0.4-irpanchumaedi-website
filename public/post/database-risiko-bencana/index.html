May 7, 2026 2 min read

🗺️ Data bersumber dari inaRISK BNPB (inarisk.bnpb.go.id). File tersedia dalam format PDF per provinsi mencakup 3 jenis bahaya: Banjir, Banjir Bandang, dan Kekeringan.
