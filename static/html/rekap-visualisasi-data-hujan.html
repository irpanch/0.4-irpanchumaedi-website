Mengapa rekap data hujan penting?

Data hujan harian mentah dari alat penakar (ARR/manual) menghasilkan ribuan baris angka yang sulit dibaca langsung. Rekap dan visualisasi mengubah data mentah menjadi informasi hidrologi yang berguna — mulai dari pola musiman, tahun basah-kering, hingga hujan ekstrem untuk desain bangunan air.

Setelah mempelajari modul ini, kamu dapat:
✓
Memahami struktur data hujan harian di Excel
Mengenali kolom Tanggal, Bulan, RR mentah, dan nilai terkoreksi — serta peran masing-masing dalam analisis.
✓
Menangani data hilang & kode anomali (8888)
Menggunakan formula IF untuk memfilter nilai tidak valid tanpa merusak urutan tanggal.
✓
Membuat rekap bulanan & tahunan dengan Pivot Table
Menghasilkan tabel pivot_sum (total), pivot_max (maks harian), dan pivot_hari_hjn (hari hujan).
✓
Membuat visualisasi yang informatif untuk laporan
Memilih jenis chart yang tepat dan menerapkan formatting profesional di Excel.
ℹ️ Data yang digunakan adalah Sta. Hujan Cemara, Bandung — salah satu stasiun BBWS Citarum dengan rekam data 26 tahun (2000–2025). Stasiun ini representatif untuk wilayah Bandung Raya yang termasuk daerah tangkapan air Sungai Citarum.

Kolom A — Tanggal

Format tanggal Excel (Date type). Digunakan sebagai sumbu waktu pada chart dan field pengelompokan di Pivot Table. Pastikan format konsisten: DD/MM/YYYY.

Kolom B — Bulan

Format bulan-tahun. Dihasilkan dari formula:

=EOMONTH(A2, 0)

Berguna untuk grouping pivot per bulan kalender.

Kolom C — RR (Data Mentah)

Data mentah dari arsip/digitasi. Nilai 8888 = data tidak terukur. Nilai 0 = tidak hujan (hari cerah).

Kolom D — Curah_hujan (mm)

Data bersih setelah filter. Nilai 8888 diubah menjadi tanda "-" (teks) agar tidak ikut perhitungan SUM/AVERAGE.

3

Menangani Data Hilang — Kode 8888

⚠️ Kode 8888 adalah kode standar BMKG/BBWS yang berarti data tidak tersedia — akibat alat rusak, petugas tidak hadir, atau arsip hilang. Kode ini wajib difilter sebelum analisis statistik karena nilai 8888 akan merusak hasil SUM, AVERAGE, dan MAX.
1
Hitung jumlah data hilang dengan COUNTIF
Gunakan untuk mengetahui berapa data yang perlu ditangani sebelum analisis.
=COUNTIF(C:C, 8888) → jumlah baris dengan kode 8888
2
Buat kolom Curah_hujan (mm) dengan formula IF
Ganti kode 8888 dengan tanda "-" (teks), sehingga Excel tidak menghitungnya sebagai angka. Nilai 0 (tidak hujan) tetap dipertahankan.
=IF(C2=8888, "-", C2) → isi di D2, salin ke seluruh kolom
3
Verifikasi dengan ISNUMBER
Pastikan sel yang berisi "-" tidak terbaca sebagai angka oleh Excel.
=ISNUMBER(D2) → TRUE = valid, FALSE = data hilang/teks
4
Hitung persentase data hilang per tahun
Wajib dicantumkan dalam laporan kualitas data sebelum analisis frekuensi atau pemodelan.
=COUNTIFS(B:B, ">=01/01/2010", B:B, "<=31/12/2010", C:C, 8888) / 365 * 100
→ % data hilang tahun 2010

Membuat Rekap dengan Pivot Table

Pivot Table adalah fitur paling efisien di Excel untuk merekap ribuan baris data harian menjadi tabel ringkasan bulanan × tahunan hanya dalam hitungan detik, tanpa formula manual.

1
Klik sel mana saja dalam tabel data_harian
Pastikan tidak ada baris kosong di antara header baris 1 dan data. Excel akan otomatis mendeteksi range tabel.
2
Insert → PivotTable → New Worksheet
Buat di sheet baru untuk kerapian. Beri nama sheet yang informatif: pivot_sum, pivot_max, atau pivot_hari_hjn.
3
Atur field di panel PivotTable Fields
Susun field sesuai kebutuhan rekap:
ROWS
→ Kolom Tanggal (group by Year)
COLUMNS
→ Kolom Tanggal (group by Month)
VALUES
→ Curah_hujan (mm)
SUMMARIZE BY
→ Sum / Max / Count
4
Buat 3 Pivot Table terpisah untuk 3 variabel:
pivot_sum → Total bulanan (mm) pivot_max → Hujan maks harian (mm) pivot_hari_hjn → Hari hujan (hari)
Contoh hasil pivot_sum — Total Curah Hujan Bulanan (mm):

🌧️ Musim Hujan (Nov–Apr)

Curah hujan >150 mm/bulan. Puncaknya di November (314 mm) dan Desember (267 mm). Dipicu oleh monsun barat dan konvergensi zona ITCZ di ekuator.

☀️ Musim Kemarau (Jun–Sep)

Curah hujan terendah di Agustus (50 mm). Dipicu oleh monsun timur yang membawa massa udara kering dari Australia. Bandung termasuk tipe hujan Monsonal (tipe A).

📊 Di Excel: Pilih baris rata-rata dari pivot_sum (row Average) → Insert → Bar/Column Chart → Clustered Column. Tambahkan series kedua berisi nilai konstan 184 sebagai garis rata-rata. Ubah tipe chart series kedua ke Line.

Tips Formatting & Penutup

Tips membuat chart data hujan yang profesional:
  • 📝 Judul & satuan selalu wajib. Contoh: "Curah Hujan Bulanan Sta. Cemara Bandung (mm)" — tanpa satuan, grafik tidak dapat diinterpretasi oleh pembaca laporan.
  • 📏 Tambahkan garis rata-rata sebagai referensi. Insert series kedua berisi nilai konstan rata-rata, ubah ke Line chart. Berguna untuk membandingkan tahun basah vs kering secara visual.
  • 🎨 Heatmap dengan Conditional Formatting. Pilih range pivot_sum → Home → Conditional Formatting → Color Scale (biru ke merah). Otomatis mewarnai sel berdasarkan nilai — pola musiman langsung terlihat.
  • 🖌️ Gunakan skema warna yang konsisten. Biru untuk curah hujan, merah-oranye untuk anomali/ekstrem. Tetap konsisten di seluruh dokumen laporan agar mudah dipahami.
  • 🔢 Data label secukupnya. Untuk bar chart tahunan, cukup tampilkan label di bar tertinggi dan terendah — terlalu banyak label justru membuat grafik sulit dibaca.
  • 🔗 Gunakan Named Range agar chart lebih fleksibel. Beri nama range (Formulas → Name Manager) sehingga mudah dirujuk dan chart otomatis ikut jika range diperluas.
